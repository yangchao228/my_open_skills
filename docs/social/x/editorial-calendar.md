## 每周执行流程

### Monday：准备

1. 为每条计划帖子选择一个证据附件。
2. 刷新平台数字，并记录 UTC 检查时间。
3. 确认帖子只有一个主张和一个行动要求。
4. 检查截图中没有密钥、私有路径或账号会话信息。

### Tuesday 至 Saturday：发布和互动

1. 用户人工发布。
2. 在未登录环境中检查链接。
3. 把真实 URL 写入本日历和 `metrics.csv`。
4. 每周选择五天，从私有观察 List 中完成每天约 15 分钟的相关回复。
5. 把“表达了试用兴趣”和“完成试用”分开记录。

### Sunday：复盘

1. 尽可能等待数据满 36 小时。
2. 更新 `metrics.csv` 中的漏斗字段。
3. 最多记录五个高质量目标受众问题。
4. 为下一周选择一个改动。
5. 前四周不调整发布时间。
