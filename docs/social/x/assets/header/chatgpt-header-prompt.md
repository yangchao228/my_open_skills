# ChatGPT X Header 生成提示词

## 语言约定

这份文档的操作说明和设计要求使用中文，方便审核和维护。只有最终需要显示在
X Header 上的三行文字保留英文，并要求 ChatGPT 精确复制。

## 使用方式

1. 在 ChatGPT 新对话中上传当前 Header 作为参考图。
2. 告诉 ChatGPT：参考图只用于理解品牌文字和颜色，不沿用当前扁平构图。
3. 完整粘贴下面的“主生成提示词”。
4. 第一轮只生成一张，避免多版本共用一张画布。
5. 如果画面满意但英文有误，继续使用“文字局部修复提示词”，不要重做整张图。
6. 如果连续两次无法准确生成英文，使用“无字背景兜底提示词”，再确定性加字。

## 主生成提示词

```text
请为一位面向全球开发者和开源社区的 AI Builder，创作一张高完成度、宽幅、具有个人品牌辨识度的 X 个人主页 Header。

我会上传一张现有 Header 作为参考。参考图只用于确认已经批准的英文文字、深海军蓝主色、青色系统信号和单个琥珀色“人的判断节点”。不要沿用参考图当前的扁平仪表盘布局、细边框、居中网格和简单折线结构。请从零重新设计，显著增强空间层次、视觉叙事、作者感和品牌记忆点。

一、品牌背景

人物是 Sundy Yang，一名 AI Builder 和开源实践者。

他把真实使用过的工作流沉淀成开放、可复用、可检查的系统，同时保留人的最终判断权。

核心视觉命题：

“人的判断，仍然是开放 AI 系统中的主权门。”

Human3.0 代表：人在 AI 时代保留认知主权、能检查系统、能覆盖系统决定，并把重复劳动沉淀成长期数字资产。

Wenchang 是一套由多个可组合 Agent Skills 构成的开放内容工作流。

二、画布和裁剪要求

- 最终交付尺寸必须是 1500 × 500 像素。
- 使用真正的 3:1 超宽横向构图。
- 如果原生生成器不支持 1500 × 500，请先在 3:1 画板内完成构图，再输出最终 1500 × 500 裁剪，不允许横向拉伸。
- 同时适配 X 桌面端和移动端主页裁剪。
- 所有重要文字放在中央安全区，大约为 x=380–1220、y=90–350。
- 左下区域必须安静、偏暗，不放重要文字和主体，因为 X 圆形头像会遮挡该区域。
- 四周保留充分留白，不让重要内容贴边。
- 缩小到手机信息流宽度时，标题仍应一眼可读。

三、整体视觉方向

营造“世界级 AI 研究工作室 × 独立开源实验室 × 高端编辑设计封面”的气质。

画面应该具有电影感、理性、安静、人本和精密打磨的质感。需要明显的空间深度和视觉叙事，不能再像扁平矢量模板、技术文档封面或通用科技仪表盘。

把背景设计成一套分层的“开放系统架构”：

- 深邃的午夜海军蓝空间；
- 半透明的建筑结构层、知识切片和细微地形等高线；
- 表示小型可组合 Agent Skills 的模块化发光节点；
- 多条青色路径发生分支、保持可追踪，再重新汇合；
- 一个琥珀色的“人的判断门”打断冷色机器系统；
- 琥珀色节点应当克制、明确，像人的意识、选择或最终批准点；
- 用版本层、证据路径、归档知识结构暗示长期积累；
- 使用克制的大气透视、柔和青色体积光、细微材料颗粒和准确控制的辉光；
- 让人感到系统延伸到画框之外，但画面中可见的部分仍然安静、清楚、可理解。

不要绘制具体人物、机器人、机械脑、人手或电脑屏幕。人的存在只通过唯一的暖色判断节点体现，让冷色机器路径与一次明确的人类干预形成对比。

四、构图

采用非对称的编辑式构图，视觉能量从左向右流动。

左下头像遮挡区保持深色和安静。

系统结构从左侧低调出现，经过琥珀色“人的判断门”，然后在右侧扩展成更丰富但仍有秩序的模块星座。

三行文字整体略偏右，嵌入空间结构中，不要像后期简单贴在背景表面。

第一行标题是最强视觉锚点。
第二行副标题安静、克制、具有思想性。
第三行证明信息精确、技术化、有可信度。

使用有意义的负空间建立强层级。画面应当像经过专业艺术指导的品牌作品，避免自动居中的模板感。

五、最终可见文字

最终画面只能出现下面三行英文。逐字符准确复制，不得改写、缩写、翻译、增加标签或虚构小字。

第一行：
AI Builder for Human3.0

第二行：
Building open systems for cognitive sovereignty

第三行：
20 VERIFIED AGENT SKILLS · WENCHANG · BUILD IN PUBLIC

六、字体要求

- 第一行：现代、专业的 grotesk 或 neo-grotesk 粗体，坚定但克制，使用白色或极浅蓝色。
- 第二行：较轻字重的现代无衬线体，冷灰蓝色，保持高可读性。
- 第三行：紧凑的等宽字体或技术感无衬线体，使用青色和严格字距。
- 必须保留原始大小写和标点。
- “Human3.0”必须保持在同一行，且拼写完全正确。
- 不要给标题做夸张描边、金属浮雕、扭曲或大面积霓虹辉光。
- 不使用猎奇的未来字体。
- 不增加任何其他文字、数字、伪代码、序列号、带文字的图表、Logo 或水印。

七、颜色和材质

- 主背景：#06111F 到 #0A1B2E 的深海军蓝。
- 系统结构青色：#48D7E8 及克制的蓝绿色变化。
- 人的判断节点：#FFB547，只允许作为唯一暖色视觉焦点。
- 主文字：#EEF6F8。
- 次级文字：#9CB8C5。
- 材质可以使用轻微磨砂玻璃、烟熏亚克力、细纸张颗粒和柔光扩散。
- 对比度必须能承受 X 图片压缩。
- 不要使用过饱和霓虹色，也不要把整张图处理得过暗。

八、完成度

最终 Header 应当像为一位认真构建产品和开源系统的人定制的品牌识别作品：高级、可信、容易记住、有明确作者感。

每一个节点、光路、间距、对齐和字体距离都应该像经过反复推敲。

背景允许复杂，但阅读体验必须简单。

通过空间层次、光线、材料和透视建立深度，不要通过增加界面组件制造复杂感。

最终作品应当接近顶级编辑设计工作室为开放 AI 研究项目制作的定制视觉识别图。

九、明确禁止

- 通用电路板壁纸；
- Matrix 代码雨；
- 赛博朋克城市；
- 霓虹科幻控制室；
- HUD 面板或虚假软件界面；
- 一排排没有意义的矩形框；
- 机器人、仿生人脸、机械脑、芯片、人手或人物肖像；
- 通用网络地球；
- 过量粒子和镜头光晕；
- 拥挤的流程图；
- 对称的企业科技模板；
- 随机字符、虚假数据、不可读小字、中文、额外英文、Logo、签名或水印；
- 暗示速度、收入、增长或流行度的虚假视觉信息。

十、输出要求

只返回一张完成后的 Header 图片。
不要制作设备样机。
不要制作 X 主页截图。
不要添加外边框。
不要把多个版本拼在同一张图里。
生成前不要解释设计方案，直接生成。
```

## 文字局部修复提示词

当整体画面满意，只有英文拼写、大小写或排版出错时，在同一对话中发送：

```text
保留当前图片的构图、系统架构、光线、颜色、材质、琥珀色人的判断节点和所有背景细节，不做任何重新设计。

这次只修复文字区域。不要重新生成整张画面，不要改变非文字区域。

把所有可见文字替换为下面三行，逐字符准确复制：

AI Builder for Human3.0

Building open systems for cognitive sovereignty

20 VERIFIED AGENT SKILLS · WENCHANG · BUILD IN PUBLIC

要求：

- 保留大小写、Human3.0 中的句点和第三行的居中圆点。
- 不出现任何其他文字、数字、标签、伪代码、Logo 或水印。
- 三行文字全部位于中央安全区。
- 第一行标题保持在同一行。
- 在 1500 × 500 尺寸下保持高可读性。
- 不修改文字区域以外的任何内容。

只返回修复后的 Header 图片。
```

## 无字背景兜底提示词

如果连续两次仍无法准确生成英文，先生成无字背景：

```text
请生成当前 X Header 视觉方案的无字背景版本。

保留高完成度的深海军蓝开放系统架构、分层半透明结构、青色可检查路径、细微材质颗粒、空间深度和唯一的琥珀色人的判断节点。

删除所有可见单词、字母、数字、标签、Logo、签名、水印和伪代码。

在画面中央略偏右的位置预留安静、高对比度的文字区域，大约为 x=380–1220、y=90–350。

左下头像遮挡区域保持深色和安静。

最终输出必须是干净的 3:1 超宽 Header，尺寸为 1500 × 500 像素。不要样机，不要边框，不要说明文字。
```

## 人工验收清单

- [ ] 文件是单张 1500×500 PNG 或 JPG。
- [ ] 桌面端能完整看到三行文案。
- [ ] 移动端裁剪后标题和证明信息仍完整。
- [ ] 左下头像不会挡住正文。
- [ ] `Human3.0`、`cognitive sovereignty`、`WENCHANG` 拼写准确。
- [ ] 证明行仍是 `20 VERIFIED AGENT SKILLS`，发布前已复核数量。
- [ ] 没有随机小字、伪代码、Logo、水印或中文。
- [ ] 只有一个琥珀色“人的判断节点”，没有到处发光。
- [ ] 画面有层次，但没有变成赛博朋克面板或通用 AI 壁纸。
- [ ] 缩小到手机宽度后，仍能先读到标题，再看到视觉记忆点。
