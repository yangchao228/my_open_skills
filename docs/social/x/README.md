# X English Launch Package

[中文](README.zh-CN.md)

This directory turns the repository's public work into a 90-day English X
experiment for Sundy Yang. It prepares copy, evidence, timing, and measurement.
The account owner still performs every profile edit, post, reply, Community
action, and final factual check.

## Start Here

1. Read [brand-system.md](brand-system.md).
2. Use the
   [ChatGPT header prompt](assets/header/chatgpt-header-prompt.md) to generate

   [x-header-1500x500.png](assets/header/x-header-1500x500.png) as the

   [first-month-posts.md](first-month-posts.md).

   [engagement-list.md](engagement-list.md).
7. Record every published URL and weekly result in [metrics.csv](metrics.csv).
