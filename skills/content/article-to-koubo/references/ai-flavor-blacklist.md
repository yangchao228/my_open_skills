# 口播版 AI 味清单

AI 味不在某几个词上，而在于说话太平均、太工整、太端着，而且总想替听众总结意义。
光禁词不够：把"首先"机械地换成"第一点"，AI 味还在。要改的是说话的方式。

这份清单分两部分：体检脚本能抓到的，和只能靠人或模型自己判断的。

## 一、脚本能抓到的（`scripts/koubo_lint.py`）

| 类别 | 典型说法 | 怎么改 |
| --- | --- | --- |
| 开场套话 | 在当今……、众所周知、让我们一起、你是否曾经、在……飞速发展的今天 | 删掉，直接用钩子开场 |
| 过渡套话 | 值得注意的是、不可否认、由此可见、与此同时、此外、总的来说、综上所述 | 删掉引子直接说，或者换成口头路标 |
| 拔高套话 | 具有重要意义、里程碑、新篇章、至关重要、彰显、助力、未来可期、拭目以待、这不仅仅是 | 别替听众总结意义，说具体会发生什么 |
| 客服腔 | 好问题、希望对你有所帮助、如果你有任何问题 | 删 |
| 假情绪 | 震撼、炸裂、令人惊叹、颠覆认知、史诗级、重磅、连续感叹号 | 换成有来由的具体反应 |
| 网络烂梗 | 家人们、宝子们、绝绝子、格局打开、主打一个 | 换成自己的话（人设卡允许的可以用 `--allow` 放行） |
| 视觉指代 | 如下图、上述、本文、笔者、详见 | 听众看不到，改成口头描述 |
| 限定词堆叠 | 在一定程度上、也许可能 | 留一个，或者说清楚 |
| 模板开场收尾 | 今天我们来聊聊、话不多说、那么问题来了、欢迎在评论区留言 | 换成这条视频独有的开头和结尾 |
| 结构套路 | 不是……而是、不仅……更、首先……其次、一方面……另一方面、答案是： | 直接说结论，只讲重要的 |
| 书面词 | 然而、因此、是否、如何、能够、存在着 | 见 spoken-style.md 对照表 |
| 书面成语 | 层出不穷、日新月异、如火如荼、息息相关 | 换成大白话 |
| 黑话术语 | 赋能、抓手、闭环、底层逻辑、链路、落地 | 见 jargon-translation.md |
| 假口语 | 说白了、其实、说实话、你发现没、对吧（太密） | 每个词大约 300 字最多一次 |
| 书面符号 | 括号、破折号、分号、列表、Markdown、表情符号 | 正文只用，。？！…… |
| 书面句式 | 一口气三个"的"、进行＋动词、被字句堆叠、四字词连排、三项以上并列 | 拆句，换动词，改主动句 |
| 气口 | 超过 22 字不停顿 | 拆开 |
| 节奏 | 连续三句一样长、短句太少、连续三句同一个开头 | 插短句，换开头 |
| 对象感 | 全稿没有"你"，"我们""大家"比"你"还多 | 对着一个人说 |

## 二、脚本抓不到，要自己判断的

1. **强凑三段式**：三个理由、三个特点、三个形容词。真实的人说话，常常两个就停了。
2. **段段金句收尾**：每段最后一句都像能单独截图的金句。删掉一半。
3. **伪深度格言**："协作是效率的语言""选择比努力更重要"。听着有道理，其实什么都没说。
4. **起跑式铺垫**："接下来我们深入看看""下面我要说的很重要"。直接说就行。
5. **跟假想敌辩论**："我不是在贩卖焦虑""我知道有人会说……"。没人这么说的话，就别替他说。
6. **过度平衡**：结尾来一句"当然，凡事都有两面性"。有立场就说立场。
7. **替听众总结意义**："这告诉我们……""这说明了……"。让事实自己说话。
8. **自问自答泛滥**：每段都用"为什么？因为……"开头。全稿 2–3 个就够了。
9. **假幽默**：网络烂梗、硬凹的谐音梗、"哈哈开个玩笑"、写进正文的"（笑）"。
10. **段落一样长**：每段三四句，长度差不多。真实的人说话有长有短，有时候一句话就是一段。
11. **编造细节和经历**："我上周有个朋友……""据统计，八成的人……"。原文没有的事实、数字和经历一律不加，需要的话写成 `[[待补：…]]`。
12. **立场缺失**：通篇都在转述，没有一句"我觉得""这个我不太信""我的建议是"。至少要有一处明确的态度。态度要么来自原文作者，要么由用户确认过。

## 三、改的时候别引入新的 AI 味

- 不要机械替换：把"首先"换成"第一个点"，把"值得注意的是"换成"重点来了"，这是换汤不换药。要重写整句。
- 不要为了活人感拼命塞口语词：说白了、其实、你发现没，塞多了是另一种 AI 味。
- 不要为了清零去硬改建议改的项：已经通顺自然的句子，就留着。
