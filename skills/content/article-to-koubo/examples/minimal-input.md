# 为什么你的 AI 智能体总是"差一口气"？

最近半年，AI 智能体（Agent）成为行业最热门的话题之一。从自动写代码到自动订机票，各类 Agent 产品层出不穷。然而，很多用户在实际使用中发现，Agent 在演示视频里表现惊艳，一到真实任务就频频"翻车"。问题究竟出在哪里？

## 一、长链路任务中的误差累积

Agent 与普通对话机器人的核心区别在于，它需要自主规划并执行一系列步骤。一个看似简单的任务，比如"帮我整理上个月的报销单并提交审批"，在系统内部可能被拆解为 20 个以上的子步骤：登录系统、检索邮件、识别发票、填写表单、核对金额……

问题在于，每一步都存在出错的可能。假设每一步的成功率是 95%——这已经是相当不错的水平——那么连续执行 20 步之后，整体成功率只剩下约 36%。也就是说，三次里面有两次会失败。这就是长链路任务中的误差累积效应。

## 二、演示与现实的差距

厂商的演示视频通常经过精心挑选，任务链路短、环境干净、输入规范。而真实场景中，网页会改版、文件格式五花八门、用户需求表述模糊，每一个变量都会进一步拉低单步成功率。

## 三、可行的应对思路

业界目前主要有三种应对思路：

1. **缩短链路**：把大任务拆成若干个小任务，每个小任务独立验收。
2. **人类在环（Human-in-the-loop）**：在关键节点设置人工确认，例如付款、提交、删除等不可逆操作之前，必须由人确认。
3. **完善评测体系**：建立覆盖真实场景的评测集，持续追踪每一步的成功率，而不是只看最终演示效果。

## 结语

Agent 的未来值得期待，但在当下，我们更应该理性看待它的能力边界。与其期待一个全能助手，不如先让它把一件小事做稳。毕竟，能稳定完成 5 步的 Agent，远比偶尔完成 20 步的 Agent 更有价值。
